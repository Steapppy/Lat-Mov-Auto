\section{Executive Summary}

\begin{tcolorbox}[infobox]
Lat-Mov-Auto is an end-of-studies internship project building a proof-of-concept Command \& Control (C2) framework focused on automating lateral movement techniques within Active Directory environments. The framework demonstrates the full attack lifecycle --- from initial reconnaissance to credential harvesting and authenticated remote execution --- using only native Windows protocols.
\end{tcolorbox}

\vspace{4pt}

The project consists of three main components: a lightweight C\# agent deployed on compromised hosts, a Python FastAPI C2 server managing agents and storing loot, and an operator CLI used to issue commands, run modules, and analyse results. The framework integrates with \textbf{n8n} for automated event notifications and is designed to be extensible with new post-exploitation modules.

As of April 2026, the core framework is operational and has been tested in a controlled lab environment. The authentication module --- the central focus of recent development --- is fully functional with automatic service detection, credential sweeping, credential spraying, and remote command execution capabilities.

\section{Implemented Modules}

\subsection{Agent (C\# .NET 10)}

The agent is compiled as a self-contained, single-file Windows executable with no external dependencies. It beacons to the C2 server at a configurable interval (default 5 seconds), receives tasks, executes them, and posts results back.

\begin{itemize}[leftmargin=16pt, itemsep=2pt]
    \item Asynchronous beacon loop with task polling via \texttt{POST /checkin}
    \item Shell command execution via \texttt{cmd.exe /c}
    \item Tool download from \texttt{/files/} server endpoint to \texttt{\%TEMP\%}
    \item File upload to server via \texttt{POST /upload} (multipart)
    \item Self-reported IP, hostname, and username on each checkin
\end{itemize}

\subsection{Reconnaissance Module}

The recon module performs fully asynchronous network scanning from the agent. It accepts a single IP or CIDR range, performs a parallel ping sweep, then scans common ports on all alive hosts. Results are returned as structured JSON and stored in the hosts table for use by downstream modules.

\begin{itemize}[leftmargin=16pt, itemsep=2pt]
    \item Parallel \textbf{ICMP ping sweep} with 1\,s timeout
    \item Port scan of 14 common ports: 21, 22, 23, 25, 80, 135, 139, 443, 445, 3389, 5985, 5986, 8080, 8443
    \item \textbf{Banner grabbing} on text-based protocols (HTTP, FTP, SMTP, SSH)
    \item \textbf{Reverse DNS resolution} for hostname discovery
    \item Results stored to \texttt{hosts} table and uploaded to loot as JSON
    \item Operator CLI renders results as a formatted table (IP / Hostname / Port / Service / Banner)
\end{itemize}

\subsection{Post-Exploitation Tool Delivery}

A generic tool-delivery model allows the operator to upload offensive tools to the server's \texttt{/files/} directory and execute them on agents on demand. Tools are downloaded to \texttt{\%TEMP\%}, executed, and any output files are automatically uploaded back.

\begin{itemize}[leftmargin=16pt, itemsep=2pt]
    \item \textbf{SharpHound} --- Active Directory enumeration; ZIP output auto-uploaded
    \item \textbf{Certipy} --- ADCS certificate template enumeration; JSON/TXT output auto-uploaded
    \item \textbf{Secretsdump / DPAPI} --- generic tool execution (Mimikatz, SharpDPAPI, etc.)
\end{itemize}

\subsection{Authentication \& Lateral Movement Module}

The authentication module is the primary focus of the current development phase. It provides multiple modes of authenticated access to remote Windows hosts using only native Windows binaries --- no third-party tools required on the agent.

\subsubsection{Supported Services}

\vspace{4pt}
\begin{tabularx}{\linewidth}{L{1.8cm} L{4cm} L{4.2cm} X}
\toprule
\theadrow Service & Protocol & Default Probe & Custom \texttt{-c} \\
\midrule
\textbf{WinRM} & HTTP/5985 via \texttt{winrs}    & \texttt{whoami \&\& hostname \&\& ipconfig} & Full stdout capture \\
\rowcolor{bgsoft}
\textbf{SMB}   & TCP/445 via \texttt{net use}    & IPC\$ connect + \texttt{net view}           & Not supported (auth only) \\
\textbf{WMI}   & TCP/135 via \texttt{wmic}       & \texttt{process list brief}                 & \texttt{process call create} \\
\bottomrule
\end{tabularx}

\subsubsection{Authentication Modes}

\begin{itemize}[leftmargin=16pt, itemsep=3pt]
    \item \textbf{Auto-sweep} --- queries recon DB for open lateral movement ports and tries all detected services sequentially, reporting success/failure per service
    \item \textbf{Forced service} (\texttt{-s winrm|smb|wmi}) --- authenticate to a specific service only
    \item \textbf{Custom command} (\texttt{-c <cmd>}) --- run any command on the remote host via WinRM; uses \texttt{shlex} parsing to handle multi-word commands with spaces
    \item \textbf{Credential spray} (\texttt{spray <target>}) --- try all DB credentials against a target, output an access matrix
    \item \textbf{Multi-target spray} (\texttt{--all}) --- one credential set against every host in the DB with lateral movement ports open
    \item \textbf{Auto-store} --- successful authentication automatically persists the credential to the DB
\end{itemize}

\subsubsection{Operator CLI Examples}

\begin{lstlisting}
# Auto-sweep all services detected by recon
authenticate -u administrator -p Password1 10.0.2.8

# Force WinRM and run a custom command
authenticate -u administrator -p Password1 -s winrm -c "net user /domain" 10.0.2.8

# Spray all stored credentials against one target
spray 10.0.2.8

# One credential against all known hosts
authenticate -u administrator -p Password1 --all
\end{lstlisting}

\section{Operator CLI Reference}

The operator CLI is an interactive REPL that communicates with the C2 server over HTTP. It operates in two modes: \textbf{global mode} for cross-agent operations, and \textbf{interact mode} scoped to a specific agent.

\vspace{6pt}
\begin{tabularx}{\linewidth}{L{3.6cm} X}
\toprule
\theadrow Command & Description \\
\midrule
\texttt{agents}              & List all registered agents with last seen timestamp \\
\rowcolor{bgsoft}
\texttt{hosts}               & List all recon-discovered hosts and open ports \\
\texttt{credentials}         & List all harvested credentials from the DB \\
\rowcolor{bgsoft}
\texttt{loot}                & List files uploaded by agents (SharpHound ZIPs, etc.) \\
\texttt{results <id>}        & Show all task results for a given agent \\
\rowcolor{bgsoft}
\texttt{interact <id>}       & Enter interact mode for a specific agent \\
\midrule
\multicolumn{2}{l}{\cellcolor{dark}\color{white}\bfseries\small\hspace{4pt}Interact mode commands} \\
\midrule
\texttt{recon <ip/cidr>}     & Queue a recon scan task \\
\rowcolor{bgsoft}
\texttt{shell <cmd>}         & Execute a shell command on the agent \\
\texttt{sharphound}          & Download and run SharpHound, upload ZIP \\
\rowcolor{bgsoft}
\texttt{certipy <args>}      & Download and run Certipy, upload output \\
\texttt{secretsdump <tool>}  & Download a tool and execute it \\
\rowcolor{bgsoft}
\texttt{authenticate ...}    & Authenticate to remote hosts (see Section 3.4) \\

\end{itemize}
